Arahan rasa: santai, senyum, seperti ngobrol ke teman di dapur sambil nunggu presto; kalimat pertama nada heran "kok bisa, ya?", "Rahasianya:" sedikit pelan seperti membocorkan, "SERATUS DUA PULUH" ditekan jelas; "Lho" protes lucu; "iya" santai mengalah; menahan tawa di "angkot sesak"; "Tapi" sedikit tegang; penutup iseng menyindir. Kalimat terakhir pelan dan digantung (nada naik, jangan ditutup). Tempo biasa, jangan dipercepat; jeda antar kalimat pendek saja.
NASKAH BACA — A3-04 Panci presto (R0, ±49 detik, 109 kata, TANPA intro)
Tanda "/" = jeda napas pendek. Kata KAPITAL = ditekan. "..." = tahan napas sebentar. Angka di kiri = detik mulai di video (patokan).

00  Daging alot / di panci presto, / kok cepat EMPUK? / Rahasianya: / airnya bisa mendidih / sekitar SERATUS DUA PULUH derajat.   (langsung bicara di detik 0, tanpa salam; heran lalu bocoran)
08  Lho, / bukannya air / mentok di SERATUS? / Di panci biasa, / iya. / Api digedein pun, / panas lebihnya / kabur bareng UAP.   (protes lucu, lalu santai)
16  Presto beda. / Tutupnya RAPAT, / uap nggak bisa kabur. / Numpuk, / tekanannya NAIK.   (tegas, cepat-pendek tapi jelas)
21  Masalahnya, / air baru mendidih / kalau dorongan uapnya / MENANG / lawan tekanan. / Kayak turun / dari angkot sesak, / dorongnya harus / lebih KUAT.   (menjelaskan santai, menahan tawa di "angkot")
29  Air harus / lebih PANAS dulu. / Makanya daging matang / jauh lebih SINGKAT.   (nada "nah, itu dia")
34  Tapi / tekanannya / nggak naik terus. / Ada KATUP / yang buang / kelebihan uap.   (sedikit tegang, lalu lega)
39  Jadi kuncinya / bukan api gede, / tapi TEKANAN. / Di rumahmu, / apa yang SELALU / dipresto? / Kirim ke teman / yang tiap masak, / apinya digedein terus...   (iseng menyindir, lalu pelan dan digantung)

Cara baca: presto = "pres-to" · digedein = "di-ge-de-in" · numpuk = "num-puk" · dorongnya = "do-rong-nya" · rahasianya = "ra-ha-si-a-nya".
Cara rekam: HP, ruangan sepi (kamar dengan gorden/kasur meredam gema), jarak mulut ±15 cm, satu kali baca tanpa berhenti. Mulai bicara langsung begitu tombol rekam ditekan (Yoga memotong hening di depan).
