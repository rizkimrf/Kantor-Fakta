Arahan rasa: santai, senyum, seperti cerita ke teman yang matanya lagi kedutan; buka dengan nada penasaran beneran (bukan kuis); "Katanya tanda rezeki" agak menggoda; "BUKAN." tegas tapi ramah, jangan mengejek kepercayaan orang tua; kagum pelan di penampang; geli di "popcorn" dan "tetap joget"; "Lho" kaget jujur; studi kecil diucapkan jujur dan tenang; batas aman serius-hangat, tidak menakutkan; penutup nada naik penasaran. Tempo biasa, jangan dipercepat.
NASKAH BACA — B4-01 Kedutan mata (R2 28 Nov; ±66 detik, 125 kata, TANPA intro)
Tanda "/" = jeda napas pendek. Kata KAPITAL = ditekan. "..." = tahan napas sebentar (±0,5 dtk). Angka di kiri = detik mulai di video (patokan).
SFX (tik-tik kedutan, pop popcorn, hik! cegukan) dikerjakan Kiki, BUKAN ditiru Bos. Langsung bicara di detik 0.

00  Kenapa matamu / bisa KEDUTAN sendiri? / Katanya / tanda REZEKI.   (langsung bicara, nada naik di pertanyaan, "rezeki" sedikit menggoda)
04  BUKAN. / Itu OTOT kelopakmu / yang berkedut sendiri.   (tegas-ramah; "otot kelopakmu" harus selesai sebelum detik 6)
07  Di kelopakmu / ada otot MELINGKAR, / kayak karet gelang. / Kedutan halusnya / disebut MYOKYMIA.   (kagum pelan; myokymia = "mi-o-ki-mi-a")
13  Diduga, / sebagian seratnya / NEMBAK sendiri, / tanpa kamu suruh. / Anehnya, / nembaknya nggak BARENGAN, / kayak popcorn / meletup satu-satu.   (geli di "popcorn")
21  Biasanya DIKAITKAN / sama begadang, / stres, / kopi, / atau mata capek / mantengin HP.   (ringan, seperti nyindir diri sendiri; HP = "ha-pe")
27  Terus, / kenapa nggak bisa / disuruh BERHENTI? / Karena gerakan ini / BUKAN perintah dari kamu. / Mau kamu pelototin / di cermin, / dia tetap JOGET. / ... Lho, / penyebab PASTINYA aja / belum dipahami penuh.   (penasaran di pertanyaan; geli di "joget"; tahan sebentar lalu kaget jujur di "Lho")
42  Satu penelitian KECIL / mengikuti lima belas pasien / yang kedutannya awet. / Setahun lebih, / HAMPIR semuanya / tetap kedutan biasa.   (jujur, tenang, sedikit lega)
53  Tapi HATI-HATI / kalau kedutannya / berminggu-minggu, / bikin mata / menutup RAPAT, / atau MENYEBAR ke wajah. / Itu waktunya / periksa ke DOKTER.   (serius-hangat, pelan sedikit, tidak menakut-nakuti)
62  Terus, / kenapa kita bisa / CEGUKAN? / Itu video berikutnya.   (nada naik penasaran, senyum; jangan ditutup seperti penutup berita)

Cara baca: myokymia = "mi-o-ki-mi-a" · kelopakmu = "ke-lo-pak-mu" · pelototin = "pe-lo-to-tin" · mantengin = "man-te-ngin" · HP = "ha-pe".
Cara rekam: HP, ruangan sepi (kamar dengan gorden/kasur meredam gema), jarak mulut ±15 cm, satu kali baca tanpa berhenti. Mulai bicara langsung begitu tombol rekam ditekan (Kiki memotong hening di depan).
Salah ucap? Ulangi kalimat itu saja lalu lanjut — nanti dipotong.
