Arahan rasa: santai dan senyum seperti cerita liburan ke teman; nada heran di awal, geli di bagian kardus, takjub di Samosir, lalu hangat dan bangga di bagian api unggun. Kalimat terakhir dibaca menggantung, nada naik, seperti mau bertanya.
NASKAH BACA — Danau Toba terbentuk dari apa? (±80 detik, 185 kata)
Tanda "/" = jeda napas pendek. Kata KAPITAL = ditekan. "..." = tahan napas sebentar sebelum kejutan. Angka di kiri = detik mulai (patokan, tidak harus persis).

00  Liburan ke Toba? / Kamu berenang di atas LUBANG. / Danau Toba terbentuk dari apa?
    (jeda 1 detik — musik intro)
08  Katanya, / gara-gara Toba, / manusia nyaris PUNAH. / Itu nanti, / ada kejutannya. / Lubangnya dulu.
13  Sekitar tujuh puluh empat ribu tahun lalu, / di bawah sini ada dapur MAGMA raksasa. / Magmanya nyembur keluar, / BANYAK banget.
20  Dapurnya jadi KOSONG. / Atapnya ambles, / kayak kardus kosong yang kamu dudukin.   (senyum) / Lubangnya lalu keisi air. / Namanya KALDERA.
27  Terus, / Pulau Samosir terbentuk dari apa? / Dari dasar lubang ini, / yang kedorong NAIK lagi. / Di atasnya masih ada endapan DANAU.
36  Nah, / soal punah. / Abu letusan ini terbang sampai AFRIKA. / Ada ilmuwan yang ngira, / manusia tinggal beberapa RIBU orang.
43  Tapi di gua Afrika Selatan, / di lapisan abu Toba... / ada bekas API unggun. / Manusia di sana tetap bikin alat batu, / sebelum, / saat, / dan sesudah abunya jatuh.   (hangat)
53  Bahkan di Danau Malawi, / lebih dari tujuh ribu kilometer dari Toba, / abunya ada. / Tapi tanda musim dingin BESAR / nggak ketemu. / Dampaknya ke iklim? / Masih DEBAT.
63  Jadi bukti terbaru nggak dukung cerita nyaris punah. / Manusianya malah BANDEL. / Dan ternyata, / memang begitu. / Kirim ke temanmu yang pernah ke Samosir / dan ngira itu cuma danau. / Bilangin: / dia berenang di KAWAH gunung api. / Terus tanya dia…   (menggantung, nada naik)

Cara baca: Toba = "to-ba" · Samosir = "sa-mo-sir" · Malawi = "ma-la-wi" · kaldera = "kal-de-ra".
Cara rekam: HP, ruangan sepi (kamar dengan gorden/kasur meredam gema), jarak mulut ±15 cm, satu kali baca tanpa berhenti.
Salah ucap? Ulangi kalimat itu saja lalu lanjut — nanti dipotong.
