Arahan rasa: santai, senyum, seperti cerita ke teman sambil makan bakso pedas; nada yakin dan sedikit iseng di kalimat pertama, heran di "biasa aja", geli di "bohongan" dan "milih sendiri", ceria di "kebagian Nobel". Kalimat terakhir ditahan sebentar sebelum "PENDATANG", nada naik seperti bocoran.
NASKAH BACA — Pedas itu rasa apa? (±75 detik, ±160 kata)
Tanda "/" = jeda napas pendek. Kata KAPITAL = ditekan. "..." = tahan napas sebentar sebelum kejutan. Angka di kiri = detik mulai (patokan, tidak harus persis).

00  Mulutmu nggak kebakar. / Otakmu yang KETIPU. / Jadi, / pedas itu rasa apa?
    (jeda 1 detik — musik intro)
07  Habis nyambel, / dahi keringetan. / Padahal suhu mulutmu / biasa AJA.   (heran)
12  Soalnya manis dan asin / itu urusan sel pengecap. / Pedas / lapornya ke saraf NYERI.   (senyum)
18  Saraf itu punya sensor PANAS, / normalnya nyala / di sekitar empat puluh tiga derajat. / Kapsaisin, / zat pedas cabai, / bikin dia nyala / di suhu TUBUH.
27  Saraf teriak KEBAKAR! / Otak panik, / nyalain pendingin: / keringat, / hidung meler. / Kebakarannya... / BOHONGAN.   (datar, menahan tawa)
33  Tapi ada yang makan cabai liar / tanpa kepedasan kayak kita: / BURUNG.   (kaget)
38  Tikus kecil malah menghindarinya. / Mamalia kayak tikus ngerusak biji, / burung nyebarin biji UTUH. / Cabainya kayak milih sendiri / siapa yang boleh MAKAN.   (geli)
47  Tim David Julius / nemuin sensor itu / pakai kapsaisin sebagai UMPAN. / Julius lalu ikut KEBAGIAN / Nobel Kedokteran / dua ribu dua puluh satu.   (ceria)
57  Jadi pedas itu bukan rasa / kayak manis atau asin, / tapi alarm panas PALSU. / Dan ternyata, / memang begitu. / Kirim ke temanmu yang bilang / "belum pedas kalau belum keringetan". / Dia lagi bangga / sama kebakaran BOHONGAN. / Oh iya, / cabainya sendiri ternyata... / PENDATANG.   (tahan, nada naik)

Cara baca: kapsaisin = "kap-sai-sin" · David Julius = "dei-vid ju-li-us" · nyambel = "nyam-bel".
Cara rekam: HP, ruangan sepi (kamar dengan gorden/kasur meredam gema), jarak mulut ±15 cm, satu kali baca tanpa berhenti.
