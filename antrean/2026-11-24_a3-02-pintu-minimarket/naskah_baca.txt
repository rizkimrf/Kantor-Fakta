Arahan rasa: santai, senyum, seperti cerita ke teman sambil jalan ke minimarket; kalimat pertama nada "eh, kamu pernah kan?", "CUEK" agak sebal-lucu, tahan napas sebentar sebelum "eh, KEBUKA"; heran-penasaran di "Kok tahu?"; nada bocoran di "Dia nyari GERAKAN, bukan orang"; menahan tawa di "bukan sombong"; tegang pura-pura di "Pintunya nutup, dong?"; lega di "BATAL nutup". Kalimat terakhir pelan dan digantung (nada naik, jangan ditutup). Tempo biasa, jangan dipercepat; jeda antar kalimat pendek saja.
NASKAH BACA — A3-02 Pintu minimarket (R0, ±55 detik, 126 kata, TANPA intro)
Tanda "/" = jeda napas pendek. Kata KAPITAL = ditekan. "..." = tahan napas sebentar. Angka di kiri = detik mulai di video (patokan).

00  Kamu lewat depan pintu minimarket, / pintunya CUEK. / Kamu melangkah ke arahnya... / eh, KEBUKA.   (langsung bicara di detik 0, tanpa salam)
06  Kok tahu / kamu mau masuk? / Lihat kotak kecil / di ATASNYA. / Itu sensor gerak. / Dia nyari GERAKAN, / bukan orang.   (penasaran, lalu "ketahuan!")
14  Di banyak pintu, / kotak itu nembak gelombang mikro, / lalu nangkep PANTULANNYA. / Kamu mendekat, / pantulannya BERUBAH, / pintu meluncur.   (menjelaskan santai)
21  Tapi kalau kamu / lewat menyamping, / pantulannya cuma berubah DIKIT. / Pintunya bukan sombong, / kamu cuma sering / nggak KEBACA.   (menahan tawa di akhir)
29  Nah, / kalau kamu BERHENTI / di tengah pintu? / Pintunya nutup, / dong?   (tegang pura-pura)
33  Ternyata, / banyak pintu punya sensor KEDUA: / berkas infra merah / di celahnya. / Badanmu motong berkas itu, / pintu BATAL nutup.   (nada "nah, ini dia", lalu lega)
41  Jadi satu pintu, / DUA tugas: / nebak kamu mau masuk, / jaga kamu di tengah. / Pintu cuek? / Kamu tim LAMBAI / atau MUNDUR? / Kirim ke teman / yang suka NGETES pintu. / Pas dia lewat / depan pintu minimarket...   (iseng, lalu pelan dan digantung)

Cara baca: minimarket = "mini-market" · infra merah = "in-fra me-rah" · ngetes = "nge-tes" · nangkep = "nang-kep".
Cara rekam: HP, ruangan sepi (kamar dengan gorden/kasur meredam gema), jarak mulut ±15 cm, satu kali baca tanpa berhenti. Mulai bicara langsung begitu tombol rekam ditekan (Yoga memotong hening di depan).
