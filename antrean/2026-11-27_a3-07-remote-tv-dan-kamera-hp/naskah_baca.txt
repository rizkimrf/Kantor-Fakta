Arahan rasa: santai, senyum, seperti nunjukin trik ke teman di ruang tamu malam-malam; kalimat pertama datar-heran "lho, kok gelap"; tahan napas di "..." lalu kaget-takjub di "BERKEDIP"; yakin tapi santai di "nembak CAHAYA"; nada "rahasia kecil" di "ada yang BOCOR"; jelas dan ringan di bagian kode; geli di "main sandi MORSE"; ganti nada (potong) di "Soal BOCOR tadi"; nada "eh, tapi" di "nggak selalu SEMPURNA"; iseng sambil nyengir di penutup, kalimat terakhir pelan seperti ngerjain teman. Tempo biasa, jangan dipercepat.
NASKAH BACA — A3-07 Remote TV & kamera HP (R0 26 Nov; ±49 detik, 107 kata, TANPA intro)
Tanda "/" = jeda napas pendek. Kata KAPITAL = ditekan. "..." = tahan napas sebentar (±0,5 dtk). Angka di kiri = detik mulai di video (patokan).
SFX (klik, bip, pop, whoosh) dikerjakan Yoga, BUKAN ditiru Bos. Langsung bicara di detik 0.

00  Pencet remote TV, / ujungnya GELAP. / Tapi lewat kamera HP... / ada yang BERKEDIP.   (langsung bicara di detik 0, tanpa salam; tahan napas di "...", lalu takjub)
06  Remote TV umumnya / nembak CAHAYA, / cuma matamu / nggak bisa lihat. / HP SERING bisa, / gara-gara / ada yang BOCOR.   (yakin di "CAHAYA"; kalimat terakhir pelan, nada rahasia kecil)
13  Pencet tombol, / remote ngirim KODE: / kedip cepat / dari lampu di ujungnya. / Cahayanya / INFRAMERAH.   (jelas, ringan, "inframerah" diucapkan utuh)
18  Tiap tombol, / polanya BEDA. / Sensor TV / baca kedipnya, / lalu NURUT. / Kamu sama TV / kayak main sandi MORSE.   (geli di kalimat terakhir, seperti nyeletuk)
26  Soal BOCOR tadi. / Sensor kamera HP / PEKA inframerah, / jadi dikasih filter / biar warna foto wajar.   (ganti nada di "Soal BOCOR tadi", seperti buka kartu)
33  Tapi filternya / nggak selalu SEMPURNA. / Kedipnya lolos, / tampil ungu / atau putih. / Tiap HP beda, / kamera DEPAN / sering lebih jelas.   (nada "eh, tapi"; "sering" jangan ditekan keras, cukup jujur)
41  Remote rumahmu / nyempil di MANA? / SOFA, / MEJA, / KASUR, / LACI? / Tag si PENGUASA remote, / suruh pencet / ke kamera.   (akrab, nanya beneran; "PENGUASA" sambil senyum; kalimat terakhir iseng pelan, jangan ditutup seperti penutup berita)

Cara baca: remote = "ri-mot" · inframerah = "in-fra-me-rah" · Morse = "mors" · HP = "ha-pe" · nyempil = "nyem-pil".
Cara rekam: HP, ruangan sepi (kamar dengan gorden/kasur meredam gema), jarak mulut ±15 cm, satu kali baca tanpa berhenti. Mulai bicara langsung begitu tombol rekam ditekan (Yoga memotong hening di depan).
Salah ucap? Ulangi kalimat itu saja lalu lanjut — nanti dipotong.
