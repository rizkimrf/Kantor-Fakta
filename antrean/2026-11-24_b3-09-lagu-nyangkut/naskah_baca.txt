Arahan rasa: santai, senyum, seperti ngobrol ke teman yang dari tadi pagi senandung terus tanpa sadar; kalimat pertama nada "ngaku deh, kamu juga kan?", agak melamun di "MUTER terus"; heran geli di "nggak lagi dengerin APA-APA"; menenangkan santai (bukan seperti dokter) di "Tenang, ini bukan ERROR", lalu bangga kecil di "sembilan dari sepuluh"; penasaran nada naik di dua pertanyaan; cepat dan ringan di daftar pemicu (satu kalimat satu ketukan); geli di "tanpa REQUEST"; nada "eh, ini seru" di "Nah, permen karet"; jujur santai di "Bukan jurus pasti, ya"; akrab seperti nanya teman tongkrongan di penutup, kalimat terakhir iseng setengah berbisik. Tempo biasa, jangan dipercepat.
NASKAH BACA — B3-09 Lagu nyangkut di kepala (R0 23 Nov; ±55 detik, 127 kata, TANPA intro)
Tanda "/" = jeda napas pendek. Kata KAPITAL = ditekan. "..." = tahan napas sebentar. Angka di kiri = detik mulai di video (patokan).
SENANDUNG (dikerjakan Yoga, BUKAN dibaca/dinyanyikan Bos): motif "hmm-hmm" orisinal berbunyi pelan DI BAWAH baris 00, naik sebentar di jeda "[s]", lalu muncul lagi di baris 45 mulai kata "senandung". Bos tidak perlu menunggu senandung: langsung bicara di detik 0.

00  Lagu nyangkut / di kepalamu, / MUTER terus / dari bangun tidur. [s] / Kamu nggak lagi dengerin / APA-APA.   (langsung bicara di detik 0, tanpa salam; [s] = jeda napas biasa, jangan diperpanjang)
06  Tenang, / ini bukan ERROR. / Survei di Finlandia: / sekitar sembilan dari sepuluh orang / ngalamin, / minimal SEMINGGU sekali.   (santai menenangkan, lalu bangga kecil)
13  Terus, / kok bisa muter / tanpa kamu PUTAR? / Dan apa hubungannya / sama permen KARET?   (heran, nada naik di dua pertanyaan)
18  Tombol PLAY-nya / kadang ketekan sendiri. / Pemicunya / sering SEPELE.   (menjelaskan santai)
22  Satu KATA / dari obrolan. / Lewat warung tertentu. / Lagi seneng / atau galau.   (cepat, satu kalimat satu ketukan)
27  Atau pas kamu BENGONG / nunggu angkot. / DJ di kepalamu beraksi, / tanpa REQUEST.   (geli di "tanpa request")
32  Nah, / permen karet: / satu studi menemukan, / sambil MENGUNYAH, / lagu di kepala berkurang. / Kata penelitinya, / nyanyi dalam hati / pakai jalur gerak MULUT juga. / Mulut sibuk, / lagunya keseret. / Bukan jurus pasti, ya.   (ganti nada di "Nah" seperti mau cerita hal seru; geli di "keseret"; jujur santai di kalimat terakhir)
45  Lagu apa / yang nyangkut di kepalamu / sekarang? / Komen JUDULNYA. / Kirim ke teman / yang lagunya NGGAK pernah ganti. / Awas... / senandung tadi / bisa ikut nyangkut.   (akrab, nanya beneran; kalimat terakhir iseng setengah berbisik, nada menggantung, jangan ditutup)

Cara baca: ERROR = "e-ror" · PLAY = "plei" · DJ = "di-je" · REQUEST = "ri-kues" · Finlandia = "Fin-lan-dia" · ngalamin = "nga-la-min".
Cara rekam: HP, ruangan sepi (kamar dengan gorden/kasur meredam gema), jarak mulut ±15 cm, satu kali baca tanpa berhenti. Mulai bicara langsung begitu tombol rekam ditekan (Yoga memotong hening di depan).
Salah ucap? Ulangi kalimat itu saja lalu lanjut — nanti dipotong.
Jangan menyanyikan lagu apa pun di rekaman (termasuk lagu yang lagi nyangkut di kepala Bos), supaya aman hak cipta.
